# Морской бой

Небольшая игра «Морской бой» на русском языке. В репозитории есть браузерная и консольная версии.

## Браузерная версия

Откройте `index.html` в браузере. Для этой версии не нужны сервер, сборка или сторонние зависимости.

## Консольная версия

Нужен Python 3. Запустите игру командой:

```powershell
python МорскойБой.py
```

## Публикация на GitHub Pages

1. Создайте на GitHub пустой репозиторий.
2. Загрузите в него содержимое этой папки, включая каталог `.github`.
3. В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в разделе **Build and deployment → Source**.
4. После отправки изменений workflow автоматически опубликует браузерную версию. Ссылка появится в **Settings → Pages**.

Workflow публикует только `index.html`, `script.js` и `styles.css`; консольная версия и документация в сайт не попадают.
